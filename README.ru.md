# Pane

[English](README.md) · [简体中文](README.zh-CN.md) · **Русский**

**Pane — все ваши тарифы и подписки на ИИ в системном трее Windows.**

Один щелчок по значку в трее отвечает на вопросы, которые постоянно возникают
у активных пользователей ИИ: *Сколько осталось до лимита сессии Claude? Когда
сбросится недельный лимит Codex? Во сколько мне обошлось сегодняшнее использование?*

Pane — версия [OpenUsage](https://www.openusage.ai/) для Windows: бесплатное
приложение для отслеживания тарифов Claude, Codex, Cursor, Copilot, Kimi, Grok
и ещё 18 сервисов.

## Зачем нужен Pane

Если вы активно пользуетесь ИИ для разработки, вам приходится следить за
множеством подписок: Claude Max, ChatGPT/Codex, Copilot, Cursor и новыми
сервисами, появившимися в этом месяце. Каждый прячет лимиты в собственной
панели, считает использование в своих единицах и сбрасывает их по своему
расписанию. Обычно вы узнаёте, что лимит заканчивается, только когда работа
прерывается посреди задачи.

Pane собирает всё в системном трее, обновляет данные каждые несколько минут
и предупреждает о темпе расходования *до* исчерпания лимита. Проект начался
как реализация замечательного [OpenUsage для macOS](https://github.com/robinebers/openusage)
от [Robin Ebers](https://github.com/robinebers) для Windows и постепенно
превращается в более универсального помощника для работы с ИИ.

## Установка

Все бинарные файлы релизов собираются и публикуются через GitHub Actions
непосредственно из исходного кода с соответствующим тегом. Журналы сборки
открыты, а происхождение файлов можно проверить.

### winget (рекомендуется)

```
winget install Pane.Pane
```

Pane доступен в [официальном репозитории сообщества winget от Microsoft](https://github.com/microsoft/winget-pkgs/tree/master/manifests/p/Pane/Pane):
пакет прошёл проверку, хеш проверяется, предупреждение SmartScreen не появляется.

### Одна команда (PowerShell)

```powershell
irm https://trypane.xyz/install.ps1 | iex
```

Скрипт скачивает последний релиз, проверяет SHA-256, устанавливает Pane
для текущего пользователя без прав администратора и запускает приложение.
Предупреждение SmartScreen не появляется.

Передача скрипта напрямую в PowerShell выполняет то, что сервер отдаёт
в данный момент. Хотите сначала посмотреть код? Тот же скрипт в два шага:

```powershell
iwr https://trypane.xyz/install.ps1 -OutFile install.ps1
# Прочитайте install.ps1 — это короткий скрипт с комментариями, — а затем выполните:
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

(Можно обойтись без скрипта: у команды `winget install Pane.Pane` выше
хеш проверяется средствами Microsoft.)

### Установщик (.exe)

1. Скачайте **`Pane_x.y.z_x64-setup.exe`** со страницы
   [последнего релиза](https://github.com/ItsJazii/pane/releases/latest).
2. Запустите файл. Pane устанавливается для текущего пользователя в
   `%LOCALAPPDATA%\Pane`, права администратора не нужны.
3. Найдите значок Pane в системном трее рядом с часами и нажмите на него.

> **О SmartScreen:** установщик пока не подписан цифровой подписью, поэтому Windows
> может показать сообщение «Система Windows защитила ваш компьютер».
> Нажмите **Подробнее → Выполнить в любом случае**. Цифровая подпись в планах.

Тихая установка для скриптов: `Pane_x.y.z_x64-setup.exe /S`

При любом способе установки Pane поддерживает себя в актуальном состоянии:
каждая установленная копия проверяет наличие подписанных обновлений и
предлагает перезапуск одним нажатием при выходе новой версии.

### Сборка из исходного кода

Необходимы: Node.js 20+, Rust (stable-msvc), Visual Studio C++ Build Tools
и WebView2 (входит в состав Windows 11).

```
git clone https://github.com/ItsJazii/pane
cd pane
npm install
npm run tauri dev     # запуск с горячей перезагрузкой
npm run tauri build   # установщик появится в src-tauri/target/release/bundle
```

## Как это работает

Pane — небольшое приложение на Tauri v2: ядро на Rust обрабатывает данные,
а интерфейс на обычном TypeScript создаёт эффект стекла. Без Electron
и фоновых служб: один процесс размером около 10 МБ, потребляющий примерно
90 МБ оперативной памяти в режиме ожидания.

**1. Поиск ваших аккаунтов.** Официальные CLI и редакторы, которыми вы уже
пользуетесь, хранят токены входа в стандартных папках пользователя:
Claude Code — в `%USERPROFILE%\.claude\.credentials.json`, Codex CLI —
в `%USERPROFILE%\.codex\auth.json`, GitHub CLI — в Диспетчере учётных данных
Windows и так далее. Pane читает эти же файлы или использует API-ключ,
указанный в настройках, и показывает карточку каждого найденного
инструмента. Необнаруженные инструменты изначально отключены, поэтому
пустых карточек нет.

**2. Запросы к провайдерам.** Каждые несколько минут токен каждого провайдера
отправляется **только в API этого провайдера**, на те же эндпоинты использования,
которые вызывают его собственные приложения. В карточке обновляются данные
о сессиях, недельных периодах, остатке кредитов и времени сброса лимитов.
Просроченные OAuth-токены обновляются и записываются обратно, что также
сохраняет авторизацию в ваших CLI. При ошибках запросы к провайдеру ненадолго
приостанавливаются, а вместо пустой карточки показываются последние успешно
полученные данные с пометкой «Устарело».

**3. Контроль темпа расходования.** Для каждого показателя с периодическим
сбросом рассчитывается прогноз: хватит ли лимита до следующего сброса,
если продолжать в том же темпе? При ухудшении прогноза индикаторы становятся
жёлтыми или красными. По желанию можно включить уведомления Windows:
один раз за период сброса («Почти кончилось», «Кончится до сброса») или
при сбросе недельного лимита («Лимит сброшен»).

**4. Подсчёт расходов.** Ваши CLI уже записывают каждый запрос локально.
Pane читает эти журналы (Claude, Codex, Grok, OpenCode, Devin CLI, Cursor CSV,
MiniMax CLI, Kimi Code, Qwen Code, агент pi и его форки oh-my-pi / Step Code,
настольное приложение Hermes),
оценивает каждый запрос по актуальным ценам соответствующей модели
(LiteLLM / models.dev; обновление ежедневно, а при наличии неизвестных
моделей — ежечасно, чтобы цены новых моделей появлялись в течение часа)
и строит кольцевую диаграмму за сегодня, вчера или 30 дней с разбивкой
по моделям. Нажмите на кольцо, чтобы переключиться между долларами и токенами.
При подписке с фиксированной оплатой это показывает, сколько ваше использование
*стоило бы* по ценам API: лучшая реклама вашей подписки. Если публичной цены
модели нет, измеренные токены всё равно учитываются, но стоимость для них
не выдумывается. Значок ⚠ в строке расходов провайдера означает, что фактическая
стоимость немного выше показанной.

**5. Локальная обработка.** Всё описанное происходит на вашем компьютере.
Создавать аккаунт не нужно; данные о лимитах, расходах и провайдерах не
покидают ваш ПК. Pane отправляет два вида анонимных сведений о себе:
проверку обновлений (подсчёт по странам без сохранения IP-адресов) и ежедневную
статистику — она всегда включена, без переключателя в приложении
(случайный идентификатор, версия, включённые провайдеры, число успешных
и неудачных запросов к провайдерам, без сумм расходов и текстов ошибок).
Подробные условия см. в разделе [Конфиденциальность](#конфиденциальность-и-безопасность).

| Sub2API | Несколько сайтов и ключей в настройках → Sub2API; у каждого ключа своя карточка по данным `GET /v1/usage` этого сайта; ключи доступны только владельцу и отправляются только на настроенный origin |

*Индикаторы OpenCode используют официальный API использования, добавленный в

учитывается использование как с других ваших устройств, так и другими
участниками общей подписки. Если API недоступен, Pane рассчитывает использование
на этом компьютере по локальной базе `opencode.db`, как и `opencode stats`;
расходы в долларах всегда рассчитываются локально.

В планах — провайдеры с данными в базах IDE (Windsurf, JetBrains AI…)
и сервисы, о которых чаще всего просит сообщество.

## Возможности

- **Несколько аккаунтов Claude и Codex** — пользуетесь и личной подпиской,
  и рабочим или корпоративным аккаунтом? Храните второй вход в отдельной
  папке через `CLAUDE_CONFIG_DIR` / `CODEX_HOME`, и Pane покажет карточку
  каждого аккаунта со своими лимитами, тарифом, кредитами и расходами.
  Название берётся из организации или электронной почты («Claude — Acme»).
  Два входа в один аккаунт остаются одной карточкой; существующие настройки
  не меняются.
- **Сайты One/New API** — добавляйте несколько совместимых сайтов и несколько
  ключей для каждого в настройках. У каждого ключа своя карточка лимита;
  секреты доступны только владельцу на этом ПК и отправляются только
  на настроенный origin.
- **Английский, китайский и русский** — выбирайте язык вручную или используйте
  автоматический выбор по языку интерфейса Windows. Он применяется к
  всплывающему окну, трею и уведомлениям о лимитах.
- **Прогноз расходования** — цветные индикаторы и предупреждения об исчерпании
  лимита на основе темпа использования в каждом периоде сброса, а также
  необязательные уведомления Windows.
- **Локальные расходы** — кольцевая диаграмма за сегодня, вчера или 30 дней
  с разбивкой по моделям и графиком за 30 дней, рассчитанная по актуальным
  ценам моделей. При наведении сектор и его строка легенды выделяются;
  нажатие на кольцо переключает доллары ⇄ токены.
- **Накопленные сбросы лимита** — у Claude и Codex: точное время истечения
  каждого накопленного кредита и применение одним нажатием.
- **Подписанные автообновления** — Pane проверяет обновления при каждом открытии
  и каждые 4 часа в фоне. При выходе релиза номер версии внизу превращается
  в кнопку обновления: одно нажатие скачивает обновление, проверяет подпись
  и перезапускает приложение. Проверки и скачивания используют прокси
  для исходящих запросов из настроек.
- **Показатели прямо в трее** — отметьте звёздочкой до двух показателей каждого
  провайдера, и они появятся в трее как пары «логотип + процент».
- **Режим виджета** — настройка в разделе «Настройки → Общие»: Pane остаётся
  закреплённым на экране вместо автоскрытия. Перетаскивайте окно за верхнюю
  панель, фиксируйте положение кнопкой-замком, сворачивайте в узкую полосу
  40 px, которая каждые 8 с циклически показывает провайдеров
  (основной лимит, % остатка, отсчёт до сброса), или скрывайте в трей.
  При включённом эффекте «жидкое стекло» свёрнутая полоса — полупрозрачная
  стеклянная панель, сквозь которую видно рабочий стол; системная настройка
  прозрачности Windows не нужна.
- **Настройка карточек** — перетаскивайте строки показателей прямо на карточке,
  в том числе в развёрнутую область «Ещё» и обратно (Esc отменяет перенос);
  перетаскивайте карточки за ручку; или откройте экран настройки (☰), чтобы
  менять порядок показателей, скрывать строки и убирать редко нужные
  под стрелку «Ещё». Ctrl+Z отменяет действие.
- **Интерфейс «жидкое стекло»** — настоящее преломление линз на основе SDF
  в автоматически скрывающейся боковой панели и стеклянных индикаторах,
  магнитный след мини-карты и круговой переход между дневной и ночной темами.
- **Обмен карточками** — наведите курсор на карточку, нажмите ⧉ и вставьте
  результат куда угодно. Копия повторяет содержимое карточки: индикаторы,
  подсказки о темпе и график, без кнопок и ссылок, с иконкой и слоганом Pane.
- **Быстрые ссылки** — переходы к статусу сервиса и его панели в каждой карточке.
- **[Локальный HTTP API](docs/local-http-api.md)** — `GET
  http://127.0.0.1:6736/v1/usage` для скриптов, виджетов Rainmeter и оверлеев
  трансляций. Формат данных совпадает с приложением для Mac, но заголовков
  CORS нет, а проверка Host допускает только loopback, поэтому веб-страницы
  не могут прочитать данные через браузер, даже с помощью DNS rebinding.
- **Внешний вид** — системная, светлая или тёмная тема, компактный режим,
  глобальное сочетание клавиш (например, `Ctrl+Shift+U`) и необязательный
  прокси для исходящих запросов.

## Конфиденциальность и безопасность

Pane читает файлы учётных данных. Не верьте нам на слово в том, как приложение
обращается с ними, — проверьте сами:

- **[docs/privacy.md](docs/privacy.md)** — полный список всех сетевых вызовов
  Pane. Нет потоков событий, записи сессий или автоматического захвата данных.
  Проверка обновлений анонимно подсчитывает число установок за день по странам
  без сохранения IP-адресов. Всегда включённая ежедневная статистика
  передаёт версию, включённых провайдеров и число успешных и неудачных
  обновлений данных под случайным идентификатором, ни к чему не привязанным.
  Документ подробно объясняет каждое поле.
- **[docs/providers.md](docs/providers.md)** — для каждого провайдера указано,
  какие именно файлы читаются на вашем ПК и на какие эндпоинты отправляются
  содержащиеся в них данные.
- **[SECURITY.md](SECURITY.md)** — как конфиденциально сообщить об уязвимости,
  какие свойства безопасности можно проверить в исходном коде и какие
  ограничения существуют сейчас. Установщик не подписан; сами бинарные файлы
  релизов собираются через GitHub Actions из исходного кода с соответствующим
  тегом, а журналы сборки доступны публично.

Кратко: токены отправляются только в API соответствующего провайдера
по HTTPS; сохранённые ключи хранятся в `%APPDATA%\Pane` и доступны только
вашему пользователю Windows; расходы рассчитываются по локальным журналам
на вашем компьютере; HTTP API доступен только через loopback, без CORS
и с проверкой Host; подписи обновлений проверяются.
